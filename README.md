# 📸 Picture Lister Pro

A lightweight, Python-based GUI utility designed to scan image directories, clean up filename suffixes, and export a deduplicated list to a text file.

## ✨ Features

* **GUI-Driven:** No command line knowledge required.
* **Smart Deduplication:** Automatically strips common copy suffixes like `(1)`, `[2]`, or `-1`.
* **Wide Format Support:** Supports `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, and `.tiff`.
* **Progress Tracking:** Real-time progress bar for handling large directories.
* **UTF-8 Encoding:** Full support for special characters and emojis in filenames.

## 🚀 Getting Started

### Prerequisites
This script uses standard Python libraries. You only need **Python 3.x** installed.
* `tkinter` (Usually included with Python)
* `os`, `re` (Standard libraries)

### Installation
1. Clone this repository or download the source code.
2. Ensure you have Python installed by running `python --version` in your terminal.
